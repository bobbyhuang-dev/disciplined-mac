# Guides

Each guide walks through one development task that people repeat, such as adding a language, changing the root helper script or testing a Firefox-based browser. A guide is for doing, not for understanding. It links to [`architecture/`](../architecture/README.md) for background instead of explaining it.

Write a guide when a task has steps that are easy to get wrong or forget. One-line commands belong in [`CLAUDE.md`](../../CLAUDE.md#commands) instead.

Start from [`templates/guide.md`](../templates/guide.md). The rules are in [`docs/README.md`](../README.md).
